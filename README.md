# 444 — DON'T ANSWER

A native Android horror-call simulator. It shows a fictional incoming-call screen inside the app. It does **not** place or receive real phone calls, access contacts, read call history, or impersonate the Android system dialer.

## Features
- Dark immersive incoming-call interface for fictional caller **444**
- Answer / decline flow and unsettling dialogue lines
- Ringtone-like tone and vibration while the simulated call is ringing
- Fake system log and replayable scenario
- No ads, analytics, network access, contacts, or call-log permissions

## Build
Open in Android Studio, or build with Gradle 8.9 and JDK 17:

```bash
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

This is fictional horror entertainment. The incoming-call screen appears only after the user opens the app; it never makes actual calls.
